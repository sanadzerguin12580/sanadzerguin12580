## 👋 About me

I'm a high-school student who found programming through AI-assisted development — the kind of workflow where an idea becomes a working prototype in an afternoon. What began as curiosity about how websites and games are actually built turned into a habit: build it, break it, read the error, build it again.

I'm still early in this journey, and I'm honest about that. My focus right now is on the fundamentals behind the shortcuts — readable structure, clean code, and understanding *why* something works instead of only that it does. Every small project is a chance to replace a guess with a skill.
